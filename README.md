# M Tweaks

这是我针对部分 Android 应用及系统所做的一些小调整；大多数功能需要配合 Xposed 使用。

## 功能

- Pixel 启动器
  - 将全部清除操作移动到下方
  - 带主题的图标包
  - 更好的首字母排序
  - 禁止自适应图标
- Google 相册
  - 伪装成 Pixel XL
- Pixel 温度计
  - 强制启用体温计
- 系统 / 调试
  - 可信 WLAN
  - 打开应用数据/APK文件夹
  - 跳转到应用商店
  - 允许禁用系统核心应用
  - 在应用崩溃的时候显示调试信息
  - 设置所有应用为可调试
  - 拒绝强制亮度
  - 高级电源菜单

部分功能来自以下代码，并进行了修复和改进：
- [L Tweaks](https://github.com/bluesky139/LTweaks)
- [NexAlloy](https://github.com/NexAlloy/NexAlloy)
- [Lawnchair](https://github.com/LawnchairLauncher/lawnchair)
- [LineageOS](https://github.com/LineageOS/android_frameworks_base)
